Glint v0.2.2 improves how rate limiting and translation errors are handled.

## Download

| File | Description |
|---|---|
| `Glint_0.2.2_x64-setup.exe` | Installer (recommended). It upgrades the existing install in place and keeps your settings. |
| `Glint_0.2.2_x64-portable.zip` | Portable version. |
| `SHA256SUMS.txt` | Checksums. |

## Changes

- **Rate limiting no longer sends an immediate retry.** When a service returns "too many requests" (HTTP 429), Glint used to retry within a second. That only prolonged the limit, so it has been removed.
- **Rate-limited engines pause.** After an engine is rate limited, it is skipped until a pause ends:
  - The pause follows the service's own `Retry-After` time.
  - When the service gives no time, the pause is 1, 2 and then 5 minutes on consecutive limits, up to 15 minutes.
  - Cached translations still appear while the engine is paused.
  - The next successful request resets the count.
- **Clearer error messages.** Errors are now shown by type, with advice, for example:
  - Rate limiting: "Too many requests; paused, back in about 2 min", with advice suited to free endpoints.
  - Quota used up, invalid API key, connection failure, timeout and incomplete configuration each get their own message.
  - The original technical error is still available as a tooltip.
- **The Test button in Settings uses the same messages.** It always sends a real request and is not affected by a pause.

## Notes

- The free Google and Bing endpoints are unofficial and rate limited. For steady use, add an official API key in Settings → Translation, or enable a large language model service.
