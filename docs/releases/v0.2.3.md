## Changes

- **New icon, "prism".** A faceted crystal sits on the line of text inside the capture frame. Plain source text goes in, and ink-blue light comes out, as translation turning one text into another. It also matches the name *Glint*, a glint of light.
  - **Gradient:** color appears only as the dispersion of light inside the crystal, plus the ink-blue glow of the outgoing light.
  - **Texture:** a fine grain on the graphite base.
  - **Material:** faceted glass, satin capture-frame corners, and a rim light on the base.
- **Pixel-aligned 16, 24 and 32 px versions.** These are separate drawings that keep only the frame and a diamond, so the icon stays clear in the system tray and in Explorer list view.
- **New in-app icons from [qingicon](https://qingicon.com).** The popup and Settings now use one icon family throughout.
  - **Duotone at rest.** Each icon has a solid main shape and a lighter back layer. The back layer uses the text color at reduced opacity, so it adapts to light and dark themes.
  - **Solid when on.** The pin becomes solid blue when the popup is pinned. The current page in the Settings sidebar shows the solid version of its icon.
  - **New sidebar icons.** 常规 now shows a gear and 外观 a palette.
  - qingicon is Apache-2.0. It is listed under About → Open source, and its license is installed with the app as `licenses/qingicon-LICENSE.txt`.

Note: Windows caches icons. If the old icon still appears after you update, restart Explorer or sign out and back in.
