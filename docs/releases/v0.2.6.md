Glint v0.2.6 restores keyless Bing / Microsoft Translate after Microsoft retired the old Edge auth endpoint.

## Download

| File | Description |
|---|---|
| `Glint_0.2.6_x64-setup.exe` | Installer (recommended). It upgrades your existing install in place and keeps your settings. |
| `Glint_0.2.6_x64-portable.zip` | Portable version. |
| `SHA256SUMS.txt` | Checksums. |

## Changes

- **Fixed keyless Bing / Microsoft Translate.** Migrated from the retired `edge.microsoft.com/translate/auth` endpoint (HTTP 404) to Bing's web `ttranslatev3` endpoint with automatic regional redirect support (`cn.bing.com` / `www.bing.com`), process-wide session token caching (~50 minutes), and automatic refresh on token expiry (`statusCode: 205`). Official Azure API key mode is unchanged.
