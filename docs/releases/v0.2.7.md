## Changes

- **Better OCR paragraph and list layout preservation.** Narrow UI sidebars (such as GitHub repo sidebars), uniform-width CJK/English menus, wide-spaced lists, and 2-item short label pairs now keep each item on its own line (`\n`) instead of merging into a single run-on sentence, while distinct prose paragraphs, headings, and multi-column blocks are cleanly separated with blank lines (`\n\n`).
- **Paragraph and format alignment across all translation engines.**
  - **LLMs (OpenAI-compatible / DeepSeek / Claude):** Tightened the system prompt to mirror the exact paragraph count, blank lines, list breaks, bullets, and indentation of the source, with zero-latency post-stream layout reconciliation.
  - **DeepL, Google Cloud v2, and Azure Translator:** Multi-line and multi-paragraph text is now sent as a single-request array and reassembled with the exact original `\n` / `\n\n` breaks and indentation.
  - **Google free, Bing web, Baidu, and Youdao:** Preserved blank-line paragraph breaks (including compacting empty lines before Baidu's per-line API and restoring them afterwards) and reconciled collapsed/extra blank lines, CRLF, and indentation without extra HTTP requests.
