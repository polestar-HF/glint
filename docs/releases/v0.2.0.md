Glint's first release is a lightweight screenshot OCR and translation tool for Windows.

## Download

| File | Description |
|---|---|
| `Glint_0.2.0_x64-setup.exe` | Installer (recommended). Installs for the current user and needs no administrator rights. |
| `Glint_0.2.0_x64-portable.zip` | Portable version. Unzip it and run `glint.exe`. |
| `SHA256SUMS.txt` | Checksums. |

Requires Windows 10 or 11 (x64) and the WebView2 runtime, which is built into Windows 11.

The installer is not code-signed yet. If SmartScreen blocks it, click **More info → Run anyway**.

## Features

- **Screenshot translation**
  - `Alt+Q` translates, `Alt+W` recognizes text only, `Alt+Shift+W` copies the recognized text silently.
  - The screen freezes when you press the hotkey.
  - The selection snaps to windows.
  - A magnifier helps with precise selection.
  - Works across multiple monitors with different DPI.
- **Offline OCR**
  - Uses PP-OCRv6 (Chinese, English, Japanese and 47 more languages).
  - Small text is upscaled automatically.
  - Lines are merged into paragraphs.
  - If the model fails to load, Glint falls back to the built-in Windows OCR.
- **Multiple translation engines in parallel**
  - Google, Bing, DeepL, Youdao and Baidu.
  - Claude (Anthropic protocol) and any OpenAI-compatible service.
  - Results stream in, and each engine can be retried on its own.
- **New in v0.2**
  - **Add any number of LLM services.** Presets cover DeepSeek, Qwen, Kimi, Zhipu GLM, SiliconFlow, OpenRouter, Ollama, LM Studio, Claude and custom endpoints. Each can be renamed, tested, reordered and deleted.
  - **Performance data.** Settings → About shows the median and P90 over the last 300 runs for hotkey-to-selection, OCR and per-engine first-token time. **Copy diagnostics** puts this on the clipboard for feedback.
  - **Optional timing line.** The popup can show the timing of the current run.
  - **Installer icon.**
  - **"Hide when clicking elsewhere" is now off by default.**

## Known limitations

- The free Bing endpoint and Claude streaming have not yet been verified on a real machine.
- Silent OCR shows no notification when it finishes.
- API keys are stored in plain text in `%APPDATA%\Glint\config.json`.

Please send feedback with the text from **Copy diagnostics** and the logs in `%LOCALAPPDATA%\app.glint.desktop\logs\`.
