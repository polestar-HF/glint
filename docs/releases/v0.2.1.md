Glint v0.2.1 is a visual polish update. It does not change any features or configuration.

## Download

The installer is not code-signed. If SmartScreen blocks it, click **More info → Run anyway**.

## Changes

- **Consistent corners.** Every corner radius in the popup and the settings window now follows one rule: inner radius = outer radius − padding, and never less than 4 px.
  - Floating layers (menus, toasts) use 8 px.
  - Everything else uses 4 px. This matches the Windows 11 Fluent design.
  - Toggles, indicator bars, carets and scrollbar thumbs are fully rounded.
- **Continuous-curvature corners.** On WebView2 139 and later, corners use a superellipse curve, so they look smoother.
- **4 px grid.** All padding and gaps now sit on a 4 px grid.
  - The segmented control, keycaps, inputs and icon spacing are more even.
  - The popup's title-bar buttons are larger and easier to click.
- **Sharper small icons.** The app icon has pixel-aligned 16, 24 and 32 px versions, so it is clear in Explorer list view and the system tray.
