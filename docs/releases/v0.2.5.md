Glint v0.2.5 improves keyless Google Translate resilience against HTTP 429 rate limits, fixes manual retry behavior during cooldown, and adds the MIT open-source license.

## Changes

- **Google free endpoint automatic fallback.** When the default keyless `translate.googleapis.com` (`client=gtx`) endpoint returns HTTP 429, Glint now automatically fails over to `clients5.google.com/translate_a/t?client=dict-chrome-ex` and temporarily prefers it for 2 minutes to avoid repeated rate-limit stalls. Custom `baseUrl` proxies and official API key mode remain unchanged.
- **Manual retry bypasses local cooldown.** Clicking **Retry** on an individual engine card in the popup now sends a fresh request instead of being blocked by the local cooldown timer, and clears the cooldown immediately on success.
- **Gentler rate-limit cooldown.** Default backoff steps without a server `Retry-After` header are reduced from `60s / 120s / 300s` to `15s / 45s / 120s`.
- **Open-source readiness & security hardening.** Added the MIT `LICENSE`, privacy documentation in `README.md`, and secret redaction in `EngineConfig`'s `Debug` output.
